Privacy Policy

Last updated: 23 October 2026

Kya collect karte hain

  • Account data — register karne par email aur naam (Supabase Auth).
  • Device ID — ek random id jo aapke browser ke localStorage mein rehta hai, taaki bina login post kar sakein.
  • Activity logs — page views, search, filters, login success/failure, job submit, aur admin actions.
  • Diagnostics — JavaScript crash reports (browser, platform, screen, page URL, stack trace).
  • Content — aap jo vacancy/notice post karte hain.

Kya collect NAHI karte

Passwords, OTP, auth tokens, aur payment details kabhi log nahi hote. Log metadata mein sensitive keys automatically redact ho jaate hain.

Kyun collect karte hain

Service chalane, spam/scam rokne, crash theek karne, aur kaunse pages/sections useful hain ye samajhne ke liye.

Kitne din rakhte hain

Logs default 90 din ke baad automatically delete ho jaate hain. Job listings expiry par archive hoti hain.

Kiske saath share karte hain

Data Supabase (database + auth) par store hota hai. Hum aapka data bechte nahi hain.

Aapke rights

Aap apna account data dekhne, theek karne ya delete karne ke liye humse contact kar sakte hain. Browser ka localStorage clear karke device id hata sakte hain.
